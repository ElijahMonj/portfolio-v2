## 4. Featured projects

*"One built for a real community, one built purely for fun."*

### 4.1 TricyCall — IT Capstone Project

A cloud-based multi-platform tricycle hailing system with real-time chat, emergency
assistance, and GPS tracking, built for Tower TODA in the Philippines.

The project set out to address the challenges faced by commuters of Tower TODA — a
barangay in the Philippines — by providing a convenient and reliable mode of
transportation. Features include booking with a live map, real-time chat with your driver,
OTP-verified sign-in, and a feedback system.

- **Recognition:** Selected for the STI Research Symposium 2024.
- **Tech:** React Native, Expo, Google Maps, Node.js, Express, MongoDB, Socket.io, Semaphore
